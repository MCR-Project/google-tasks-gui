Application Purpose

gtasks-tui is an open-source task management application developed for Linux systems. The primary purpose of gtasks-tui is to empower users to seamlessly view, organize, edit, and synchronize their daily to-do lists and Google Tasks natively from their desktop without relying on web browsers or heavy Electron apps.

With gtasks-tui, users can manage personal and work task lists with zero network latency using an offline-first SQLite cache that automatically syncs bidirectional changes whenever an internet connection is available.

Google Tasks API Integration & Scope Usage

To provide native synchronization with your Google Account, gtasks-tui integrates with the official Google Tasks REST API.

Requested OAuth 2.0 Scope: https://www.googleapis.com/auth/tasks

Why Access is Required: This permission is required to fetch user task lists, retrieve task items, create new tasks, update task details (title, notes, due dates, completion status), and delete completed or discarded tasks upon user request.

Strict Privacy & Data Handling Guarantees:

  • Local-First Storage: Your tasks and lists are cached locally on your device in a local SQLite database file.
  • Secure Token Storage: OAuth 2.0 authentication credentials and tokens are encrypted using your system's native keyring (Linux Secret Service / KWallet).
  • Direct Encrypted Communication: All network requests occur directly between your local machine and Google's official endpoints (https://tasks.googleapis.com) over HTTPS/TLS.
  • Zero Server Transmission: gtasks-tui operates without any middleman or external servers. No user data, analytics, or credentials are transmitted to MCR-Project or third parties.
  • No AI/ML Training: Google User Data accessed by gtasks-tui is strictly used for core task management functionality and is never used for training Artificial Intelligence or Machine Learning models.

Key Application Features

⚡ Offline-First Architecture

Read, write, edit, and organize tasks even when disconnected from the internet. Changes queue automatically in SQLite and sync when reconnected.

🖥️ Modern GTK4 Desktop GUI

Sleek, native GTK4 & Libadwaita user interface designed following modern GNOME desktop standards.

⌨️ Terminal Dashboard (TUI)

Includes a keyboard-driven terminal dashboard powered by Ratatui for terminal enthusiasts.

🧠 Natural Language Date Parsing

Type task descriptions like "Submit report tomorrow" or "Buy milk today" to automatically set due dates.

🔐 OAuth 2.0 PKCE Security

Authenticates directly via secure OAuth 2.0 PKCE loopback flow and stores tokens safely in your system keyring.

🌲 Subtask Hierarchy

Full support for multi-level nested task hierarchies, parent-child task relationships, and subtask ordering.
